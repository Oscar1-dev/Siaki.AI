# ADR 0019: Identity inventory contains metadata, never credentials

Status: Accepted for Phase 20.

## Decision

The identity registry is a Rust-owned SQLite inventory of dedicated accounts, ownership-proof classification, MFA posture, recovery-control confirmation, and opaque Windows Credential Manager target references. It has no secret input contract and no credential write path.

Passwords, API tokens, session cookies, OAuth codes, recovery codes, private keys, and proof material are structurally absent. Unknown request fields are rejected. Vault references are generated by the core and remain `reference_only`; `credentialPresent` is always false until a future provider-owned or OS-backed provisioning phase is explicitly implemented.

Identity records are not connected to conversation context, memory, model adapters, autonomous planning evidence, or logs. Login hints are owner-facing private metadata and must not be copied into those systems.

## Consequences

- SAIKI can inventory owner-controlled accounts without collecting credentials.
- MFA and recovery posture can be audited without storing recovery material.
- A vault reference does not imply a credential exists.
- Provider-specific verification, onboarding, recovery, and credential use remain unavailable.

# SAIKI

SAIKI is a Windows-first, local-first autonomous digital operator and animated desktop companion, delivered in gated phases.

## Current status

**Phase 00 — Architecture freeze.** Runtime implementation is blocked until the architecture contracts, risks, and acceptance gates are reviewed and accepted.

This phase contains only normative documentation, typed boundary contracts, diagrams, and checks. It does not contain a desktop runtime, autonomous execution, model integration, or credential handling.

Start with [repository rules](AGENTS.md), the [architecture freeze](docs/architecture/README.md), [security policy](SECURITY.md), [acceptance matrix](docs/phase-00/acceptance-matrix.md), and [typed contracts](contracts/src/index.ts).

Run `npm install` and `npm test` to verify Phase 00. The repository name is `Siaki.AI`; the product name is **SAIKI**.
